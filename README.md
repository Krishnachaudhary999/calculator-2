# Calculator

A simple web calculator built with HTML and JavaScript. It adds, subtracts, multiplies and divides two numbers.

## How to use

1. Open `index.html` in any web browser.
2. Type a number in the first box.
3. Pick an operation: addition, subtraction, multiplication or division.
4. Type a number in the second box.
5. Click `=` to see the result.

Dividing by zero shows an error message instead of a result.

## Files

- `index.html`: the calculator form
- `calculation.js`: the calculation logic
